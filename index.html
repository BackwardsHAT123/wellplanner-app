Click an empty slot to plan a new well there. It copies this well’s design and moves its targets by the same offset as the surface. Click a filled slot to open that well.

▸Lateral spacing

Sets the distance between laterals. The reference well keeps its targets. Every other horizontal well gets a copy of them, moved sideways by a multiple of the spacing, in the same order as the surface locations.
Stagger moves every other lateral (1st, 3rd… from the reference) deeper by that many feet; use a negative number for shallower. This overwrites the target positions of the other wells.

Other wells on the pad are included automatically (for those, the alert only counts below the shallower of the two kickoffs, since parallel vertical holes sit one slot apart). The distance alert is center-to-center; the separation factor comes from the simplified survey-uncertainty model below.

Wells from this tool as offsets

Wells in this project are always compared with each other. Add wells from another saved plan (for example, ones not on the state’s layer yet) as reference copies: they are drawn on the plots and checked for clearance like any other offset. A reference is a frozen copy, so adding the same well again replaces it.

Drilled wells from state records

Turn on “Include wells drilled in the sections” at the top of the Plots tab to list them here.

Survey uncertainty (screening)

Simplified model: random and systematic inclination and azimuth error plus depth scale error, with rounded values for typical tools. It is not an ISCWSA tool-code calculation and the values are not checked against one. Use it to flag wells for a proper anti-collision run, not to replace it. Separation factor = center distance / (2.79 × combined 1-sigma error along the line between the wells).
